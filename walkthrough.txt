# Walkthrough — Backend & Frontend Restructuring

## Overview
LeaveDesk is a professional, enterprise-grade HR Leave Management System styled like Keka, Zoho People, and BambooHR. This walkthrough documents the completed tasks for both the Django REST API backend and the React (Vite) frontend.

---

## 1. Frontend Restructuring & Architecture

We implemented a highly modular, clean folder layout to decouple core layers, state, routing, and UI views.

### Directory Structure
- src/api/ — API wrappers for request/response logic using Axios.
- src/components/Layout/ — Main app shell layouts (collapsible Sidebar and TopBar header).
- src/components/UI/ — Reusable elements (badges, buttons, skeletons, toast, paginator, confirm dialog).
- src/components/Leave/ — Special modals (Apply Leave, Rejection reason textarea).
- src/context/ — AuthContext tracking token in-memory and user profile.
- src/pages/ — Page modules partitioned by role (auth, employee, manager, hr, shared).

### Core Infrastructure & API Integration
1. axios.js: Configures a base client with interceptors. Dynamically injects Authorization: Bearer <token> from memory (window.__authToken) on request. Listens for 401 Unauthorized responses and fires a global log-out redirect.
2. Auth & Business logic wrappers: 
   - auth.api.js (login, logout, profile rehydration, employee CRUD, department manager assignment)
   - leave.api.js (leaves, holidays, delegate approvers)
   - balance.api.js (my balances, organization balances report)
   - reports.api.js (dashboard summary counts, leaves listing, CSV export)

### State & Navigation Shell
1. AuthContext.jsx: Session persistence by querying GET /api/accounts/profile/ using an in-memory token on boot. Emits events for logout.
2. RootLayout.jsx: Implements the exact layout shell grid to prevent panels overlapping. Employs a collapsible sidebar and sticky header wrapper:
   ```jsx
   <div className="flex h-screen overflow-hidden bg-slate-50">
     <Sidebar />  {/* Collapsible (w-64 to w-18) */}
     <div className="flex flex-col flex-1 min-w-0 overflow-hidden">
       <TopBar />
       <main className="flex-1 overflow-y-auto p-6">
         <Outlet />
       </main>
     </div>
   </div>
   ```

## 2. Shared & Role-Based Pages

### A. Authentication
- LoginPage.jsx: Split screen mockup with professional branding on the left, email/password credentials with show/hide password toggle on the right.

### B. Employee Views
- EmployeeDashboard.jsx: Contains personalized greetings, remaining days donuts (SVG circular metrics), a summary table of recent requests, and an upcoming approved schedule container.
- MyLeaves.jsx: Tabbed leave filtering with pagination, cancel triggers, and inline search.
- ApplyLeaveModal.jsx: Modal window calculation of working days (filtering weekends and company holidays in real-time) with proxy employee selector dropdowns.

### C. Manager Views
- ManagerDashboard.jsx: Overview widgets, Pie/Bar chart visualizations of pending requests by employee name and leave type, and a pending approvals grid.
- PendingRequests.jsx: Directory of pending approvals with optimistic UI state transitions, Approve confirm boxes, and Rejection reason overlays (min 10 characters text validation).

### D. HR Admin Views
- HRDashboard.jsx: Aggregate dashboard metrics, leave status donut charts, department bar charts, and CSV report download controls.
- LeaveReports.jsx: Multi-field filters panel (dates, status, employee, department) coupled with CSV export triggers and sticky table headers paginated at 20 items.
- EmployeeBalances.jsx: General staff balance listings with consumption percentage meters color-coded according to remaining values (emerald green for >50%, amber for 20-50%, red for <20%).
- Employees.jsx: Side-by-side create employee panel and staff directory table containing status active toggles.
- Departments.jsx: Listing of departments with inline managers dropdown reassignments.

### E. Shared Directory
- Holidays.jsx: Calendar grouped by year. Adds holiday forms and delete buttons for HR, and read-only views for Employees/Managers.
